      ☁️ Cloud sync — share LIVE across browsers & devices

      Connected ✅ Every change now syncs to the cloud automatically. Share ONE link — stakeholders open it and immediately see the live dashboard. No downloads, no setup, no pasting links on their side.

      Right now changes are saved only in this browser — other browsers/computers won't see them until you connect a cloud link (one-time, ~3 minutes, free).

      Option 1 — Firebase (recommended, most reliable, free):

      1. Open and sign in with any Google/Gmail account
      2. Click Add project → name it e.g. factory-tracker → Create project (skip Google Analytics)
      3. Left menu: Build → Realtime Database → Create Database → location asia-south1 (Mumbai) → Next → choose Start in test mode → Enable
      4. Copy the database URL shown at top (e.g. https://factory-tracker-default-rtdb.firebaseio.com)
      5. Optional (recommended): open the Rules tab and paste: {"rules": {".read": true, ".write": true}} → Publish (so it never auto-locks)

      Option 2 — your own hosting (PHP): upload the included sync.php next to the tracker on your hosting, then paste its link below.

      Option 3 — advanced: any JSON API link that supports GET + PUT.

      🔒 Edit-link password (for the team edit link)

      Team members opening the edit link will be asked for this password. The read-only shareholder link is never affected. Use a decent-length password.
